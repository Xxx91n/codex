## 维护流程（per ADR-0006 决策 3，每次上游 merge 强制）

1. 同步前：`git fetch upstream`，以 merge-base 口径量化 ahead/behind（禁 tag 口径）。上次执行（2026-09-12 票 32）：behind 710 / ahead 90 → merge commit 0743507444 → behind 0 / ahead 91。
2. `git merge upstream/main`（never rebase）；冲突预期收敛在本清单全部 adapt 条目。
3. 逐条裁决：adapt 条目在新形态重放意图并更新「最后裁决」日期；apply 条目确认未被误改；清单外新分歧先登记再裁决。
4. 有新决策 → 新 ADR（Nygard，docs/adr/NNNN 递增）；仅重放 → 只刷新本清单日期。
5. 验证往返：CI 全绿（fork-health wiremock 三件套 + check job）后允许推远端；本机零构建（CI-only 红线）。
